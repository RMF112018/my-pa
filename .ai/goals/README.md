# Goals

Each substantive implementation goal belongs in its own directory and must record, at minimum:

- goal and work-item identity;
- repository, branch/worktree, base, head, and PR identity;
- objective, scope, acceptance criteria, constraints, and prohibited actions;
- approved plan and authorization boundary;
- test/evidence results;
- review outcome, unresolved findings, and final state.

Directory presence does not activate a goal.
