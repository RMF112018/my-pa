# Repository Governance Router

This repository does not duplicate the wider Workspace/AEOS corpus.

For repository execution, use this order:

1. [`/AGENTS.md`](../../AGENTS.md) — principal repository policy and authority boundaries.
2. [`/AI_OPERATING_MANUAL.md`](../../AI_OPERATING_MANUAL.md) — detailed agent execution guidance.
3. [`/CONTRIBUTING.md`](../../CONTRIBUTING.md) — contribution workflow.
4. [`/SECURITY.md`](../../SECURITY.md) — security/privacy handling.
5. [`/docs/00_REPOSITORY_SOURCE_INDEX.md`](../../docs/00_REPOSITORY_SOURCE_INDEX.md) — current technical documentation router.
6. the nearest current technical reference and accepted ADR.

Authenticated repository/GitHub state governs engineering identity. The cleaned MY-PA Drive library may supply accepted product/UX intent and durable evidence, but it does not supersede executable repository truth.

Goal, authorization, review and evidence artifacts may live under `.ai/` when repository governance requires them. Their existence does not activate a goal or grant implementation, merge, deployment, production or risk authority.

This file is a router only and contains no independent product or technical documentation.
