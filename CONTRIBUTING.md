# Contributing

The repository is currently in architecture-bootstrap state.

Before changing files:

1. read `AGENTS.md`, `AI_OPERATING_MANUAL.md`, and `docs/00_REPOSITORY_SOURCE_INDEX.md`;
2. bind work to an approved objective, branch, base SHA, path scope, and acceptance criteria;
3. preserve neutral `my_pa` / `MY_PA_` naming;
4. keep source-provider and managed-document responsibilities separate;
5. run proportional validation and disclose failures.

Do not add runtime services, database migrations, external connectors, credentials, schedules, or deployment assets merely because their directories exist.
