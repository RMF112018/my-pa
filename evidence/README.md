# Evidence

Store concise, reproducible evidence summaries here only when repository or review governance requires them. Bind every record to the exact repository, branch, commit/tree, goal/work item, test command, and evidence source.

Do not store credentials, private personal data, unredacted source documents, or hidden reasoning.

- [`acceptance/`](acceptance/RELATIONSHIP-MEMORY-RM-AC-20260822.md) — acceptance matrices for accepted feature contracts. Each row names the test that fails if the property stops holding, so a criterion cannot be marked satisfied on the strength of a docstring.
